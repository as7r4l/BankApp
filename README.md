# SpiritBank 

Концепт геймифицированного необанка для iOS. Проект объединяет классические финансовые продукты с встроенными мини-играми, виртуальной экономикой и механизмами вирального роста.

## Ключевые возможности

### Финтех-модуль
* **Витрина продуктов:** Кастомный UI (SwiftUI) для отображения банковских карт с адаптацией под темную/светлую темы.
* **Backend-интеграция:** Асинхронное взаимодействие с удаленной базой данных PostgreSQL через Supabase.
* **Управление сессиями:** Авторизация и привязка сгенерированных данных карт к профилю пользователя.

### Мини-игра «Card Slash» (SpriteKit)
* **Slice-механика:** Геймплей в стиле Fruit Ninja со спавном карт и бомб. Динамически возрастающая сложность и скорость генерации объектов.
* **Кастомная физика разрубания:** Математический расчет векторов свайпа и динамическая подмена точек привязки (anchor points) для реалистичного распада объектов на части.
* **Оптимизация (60 FPS):** Легковесная система частиц на базе `SKSpriteNode`, обеспечивающая плавный рендеринг при быстрых движениях.

### Экономика и Вовлечение
* **Колесо Фортуны:** Ежедневная рулетка, построенная на алгоритме **взвешенного рандома** (Weighted Probability). 
* **Реферальная система:** Генерация пригласительных QR-кодов на лету через `CoreImage` и нативный шаринг ссылок через `UIActivityViewController`.

## Стек технологий

* **Язык:** Swift
* **UI-фреймворки:** SwiftUI, UIKit
* **Геймдев:** SpriteKit
* **Изображения:** CoreImage
* **Backend:** Supabase (PostgreSQL)
* **Многопоточность:** Swift Concurrency (async/await)

## Установка и запуск

1. Склонируйте репозиторий:
`git clone https://github.com/YOUR_USERNAME/SpiritBank.git`
2. Откройте проект в Xcode (требуется версия Xcode 15.0+ и iOS 16.0+).
3. Дождитесь автоматической загрузки Swift-пакетов (Supabase).
4. Запустите проект на симуляторе или физическом устройстве (Cmd + R).
